## 已发现问题

1. **[阻断] 载入死亡存档后进入不可恢复的故障态**
   - 画面同时显示顶部“房间状态异常”和“死亡回顾”。
   - 死亡回顾底部只有分隔线，没有应有的“E 继续”或保存状态提示。
   - 使用外置键盘驱动分别发送 `E:120ms` 和 `E:1000ms` 均无响应；此时逻辑未开放继续操作，并非按键未送达。
   - 结果：玩家无法从该存档继续游戏，也没有可见的重开或恢复入口。

2. **[高] 死亡回顾文字可读性仍不足**
   - 1280×720 实机截图中，正文笔画偏细、整体对比度低；顶部房间状态文字几乎融入背景。
   - 多个中文字符边缘发虚，数值和标签需要放大截图才能可靠辨认。

## 自动化环境限制（不计为游戏功能缺陷）

- Windows Graphics Capture 对当前 OpenGL/raylib 窗口返回白屏；因此画面结论统一以游戏内 F12 生成的真实截图为准。
- 桌面控制接口的普通按键会受中文输入法影响；试玩输入改用仓库现成的独立 `arpg_keyboard_driver.exe`。
