生产统计范围为 `src/**/*.cpp`、`src/**/*.h`、`src/**/*.hpp`、`src/**/*.cxx`，均由实际命令生成。主统计口径为**物理总行数**：每个已纳入文件由 `git show <commit>:<path>` 输出的全部行计数，包含空行；最大文件排名、表内行数、总计和变化均使用该口径。**不设行数通过阈值。**

复现命令（在仓库根目录的 PowerShell 中执行；将 `$commit` 依次设为 `3e4b861` 与 `HEAD`）：

```powershell
$items = foreach ($path in (git ls-tree -r --name-only $commit -- src | Where-Object { $_ -match '\.(cpp|h|hpp|cxx)$' })) {
  $lines = @(git show "${commit}:$path")
  [pscustomobject]@{ Path = $path; Physical = $lines.Count; NonBlank = (@($lines | Where-Object { $_ -match '\S' })).Count }
}
$items | Sort-Object @{Expression='Physical';Descending=$true}, @{Expression='Path';Descending=$false} | Select-Object -First 15
$items | Measure-Object Physical -Sum
$items | Measure-Object NonBlank -Sum
```

其中 `NonBlank` 仅为辅助信息，指含至少一个非空白字符的行；它不参与最大文件排名或主统计变化。
