# 拾取吸入背包动画设计

## 目标

保留现有掉率、1.5 米自动拾取、原子存档事务和生命药规则。装备或材料成功进入背包后，用明确的屏幕动画表现“从掉落位置吸入背包”，解决自动拾取发生太快、玩家看不到掉落反馈的问题。

## 行为

- 仅在拾取事务成功提交后播放；失败、回滚、恢复或故障状态不播放。
- 装备使用原地面装备图标与品质颜色；材料使用原材料图标与颜色。
- 图标从最后一个地面世界坐标出发，沿上拱曲线加速飞向角色腰后的背包位置。
- 飞行约 0.45 秒，到达后角色腰侧短促闪出收纳光环；暂停时动画冻结。
- 房间切换或战斗瞬态清理时清空未完成动画，避免跨房间残留。
- 生命药直接治疗，不伪装成进入背包，本任务不改变它。

## 数据与边界

- 不修改存档格式、掉落结构或拾取事务。
- 装备由成功的 `LootPickupReceipt` 与上一帧同 `item_id` 地面记录配对。
- 材料由新的 `MaterialPickupReceipt` 与前后快照中消失的地面材料配对；清房批量拾取也可产生受限数量的动画。
- 动画状态使用固定容量 12，不分配堆内存。容量满时替换最接近结束的一项；大量清房拾取不会无限增长。
- 轨迹计算与渲染分离：纯状态/轨迹可做无窗口单元测试，raylib 绘制只消费计划。

## 验收

- 测试锁定：成功拾取只触发一次、失败不触发、装备和材料均使用正确起点/图标、轨迹向背包收敛、暂停冻结、固定容量无分配。
- Windows Release 使用确定性 seed 6118：击杀保证掉落的 ordinal 158，接近触发自动拾取，连续内部截图应显示从 `Shadow Hood` 掉落位置飞向角色腰后，最终背包数量增加。
