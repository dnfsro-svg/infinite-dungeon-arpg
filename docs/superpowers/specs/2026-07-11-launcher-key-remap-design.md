# 取消重击并将上挑改到 L 键设计

## 1. 目标

Stage 1 战斗实验室不再保留重击动作。删除原 `L Heavy` 的规则和数据，把现有 `U Launcher` 原样迁移到 `L` 键，`U` 不再绑定战斗动作。

此前提出的“L 重击固定浮空 0.5 秒”方案作废。本设计沿用现有上挑的自然抛物线，不增加固定浮空时长。

## 2. 最终键位

- `W/A/S/D`：移动。
- `J`：地面三段轻攻击；空中一次轻攻击。
- `K`：跳跃。
- `L`：上挑。
- `U`：无绑定。
- `R`：重置战斗实验室。
- `F1`：切换调试盒绘制。
- `F12`：保存截图。
- `Esc` 或窗口关闭按钮：退出。

HUD 只显示有效操作，战斗提示改为 `WASD Move  J Light  K Jump  L Launcher`，不再显示 `L Heavy` 或 `U Launcher`。

## 3. 战斗规则

上挑继续使用现有定义：

- 前摇 7 tick、有效 4 tick、后摇 17 tick。
- 伤害 38、破韧 18。
- 中等反馈、水平击退速度 1.2、垂直初速度 9.5。
- 浮空目标继续按现有重力自然上升、下降，触地后进入倒地。
- 轻型目标继续应用 1.25 倍冲量，因此比普通目标飞得更高、浮空更久。
- 未破韧重甲仍为霸体，不接受击退或浮空；造成破韧的同一次上挑立即击飞。

删除原重击的 14/5/22 帧数据、90 点伤害、40 点破韧、强击退、重反馈和直接倒地结果。J3 仍保留现有重反馈与倒地能力。

## 4. 代码边界

- 从输入动作枚举删除 `Action::heavy`。
- 从攻击编号删除 `AttackId::heavy`，攻击数量由 6 改为 5。
- 从集中攻击表删除重击条目，不保留不可触发的死数据或别名。
- 玩家状态机不再消费重击动作；上挑的状态机规则保持不变。
- raylib 输入桥改为 `KEY_L -> Action::launcher`，删除 `KEY_U` 战斗映射。
- 渲染 HUD 更新键位文本，其他反馈、音频和调试绘制不变。
- Combat Core 继续不包含或链接 raylib，不引入动态分配。

项目当前没有存档兼容需求，因此枚举值收缩不需要迁移旧存档。事件中的攻击编号随新的五攻击目录保持一致。

## 5. 测试与验收

按测试先行完成以下覆盖：

1. 攻击目录恰好包含 J1、J2、J3、上挑、空中 J 五项。
2. 目录中不存在重击定义，上挑的全部既有数值保持不变。
3. 玩家在地面接收上挑动作后进入上挑攻击；不再存在重击输入路径。
4. 普通目标被上挑后进入自然浮空；轻型目标的垂直冲量仍为普通目标的 1.25 倍。
5. 未破韧重甲拒绝浮空，破韧命中立即浮空。
6. J3 的重反馈、击退和倒地回归测试继续通过。
7. raylib HUD 只显示 `L Launcher`，源代码中不存在 `KEY_U` 战斗映射。
8. 36,000-tick 确定性、零热路径分配和零事件溢出压力测试继续通过。
9. Core Debug、Full Debug、Full Release 的 Fresh CTest 与直接测试程序全部通过。

可见验收时按 `L` 应触发上挑；按 `U` 不产生动作；游戏其余键位和退出清理保持正常。

## 6. 范围限制

- 不调整上挑数值、自然浮空时间或视觉反馈等级。
- 不增加新的攻击、键位自定义或手柄支持。
- 不修改房间循环、敌人 AI、地下城和 Stage 2 内容。
