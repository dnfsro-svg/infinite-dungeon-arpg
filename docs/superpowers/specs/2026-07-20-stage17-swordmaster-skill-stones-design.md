# Stage 17：剑圣技能石插槽设计

## 目标

为当前单角色地下城 ARPG 增加五个主动技能石插槽。键盘 `1`～`5`
分别施放对应槽位的主动技能。首批交付两个剑圣风格的技能石：

- 槽 1：**拔刀斩**——短前摇后的近距离扇形剑气，造成一次高伤害并击退。
- 槽 2：**极·鬼剑术（暴风式）**——较长前摇、持续剑阵多段攻击、终结落剑爆发。

槽 3～5 为空。每个主动技能槽拥有五个辅助技能石位置；本阶段只持久化并
显示这些空位，不提供辅助石掉落、装卸、效果或数值。

## 范围与非目标

本阶段实现技能石数据、存档、输入、战斗行为、HUD/暂停页可见状态和测试。
不改动既有 J/K/L/WASD 输入、武器普攻、材料/装备掉落、被动星盘和强化规则。
不使用 DNF 的视觉、音频、文本素材；技能以当前游戏的原生几何特效、音效和
动画节奏呈现。

## 槽位与保存

角色拥有固定数组 `active_skill_slots[5]`。每项包含主技能石 ID 和五个辅助
槽位 ID；空位为 `none`。新档默认槽 1=拔刀斩、槽 2=暴风式、槽 3～5 为空，
全部辅助位为空。旧档迁移到同一默认装配，不丢失既有角色、装备、材料或进度。

辅助槽位在本阶段仅供 UI 显示，战斗计算不会读取它们。这个边界确保后续加入
辅助石时不会修改主动技能槽、输入或保存格式的所有权模型。

## 输入、冷却与可用性

`1`～`5` 是五个主动槽的唯一施放键。空槽按键无副作用。技能在角色死亡、
房间过渡、暂停、硬直或自身施放期间拒绝施放；冷却未结束也拒绝施放。施放
成功只启动该技能自身冷却，不影响既有普攻、跳跃和上挑。

HUD 显示五个槽位：技能石名称/图标、按键、冷却遮罩；空槽显示空石位。暂停
页显示当前主技能石和五个辅助石空位，不提供编辑操作。

## 战斗规格

### 拔刀斩

- 目标方向：角色当前朝向。
- 时序：短前摇，单次判定，短后摇。
- 范围：角色前方宽扇形。
- 效果：物理近战伤害、明确击退、原生斩击弧光。
- 命中：同一目标在一次施放中最多一次。

### 极·鬼剑术（暴风式）

- 目标位置：施放开始时锁定角色前方的剑阵中心；施放中不跟随鼠标或目标。
- 时序：前摇、固定次数多段剑阵、终结落剑、后摇。
- 效果：每段小范围物理伤害与轻微牵制；终结段更高伤害和击飞/击退。
- 命中：每段对每个目标最多一次；终结段独立结算。
- 中断：死亡或房间转换取消未完成施放，不保留未触发伤害。

数值将采用现有物理伤害、击退和击飞/浮空管线，倍率、半径、帧数和冷却为
具名常量并由测试冻结；不引入新伤害类型。

## 架构与事务

技能石目录、角色技能装配和技能冷却状态与装备/材料状态边界分离。运行时由
战斗世界接收明确的“请求施放”命令，不直接读取 Raylib 输入。平台层只把
`1`～`5` 转成槽位请求，HUD 只消费不可变快照。

技能装配修改尚不存在，因此本阶段不创建新的保存事务 UI；默认装配随存档
编码/迁移加载。战斗期间的冷却、前摇和剑阵实体为房间瞬态状态，不能写入
检查点或在读档后凭空恢复。

## 测试与验收

- 单元测试：默认五槽、旧档迁移、空槽拒绝、冷却、状态拒绝和快照展示。
- 战斗测试：拔刀斩单命中/击退；暴风式锁定中心、多段命中上限、终结段与取消。
- 平台测试：`1`～`5` 映射、HUD 五槽与暂停页每槽五个空辅助位。
- 持久化测试：新布局往返、旧版本迁移和非法技能石 ID 拒绝。
- Raylib 验收：1280×720 下五槽 HUD、两技能实际施放和暴风式终结可见。

## 完成标准

角色可用 `1` 施放拔刀斩、`2` 施放暴风式；`3`～`5` 安全空置。五个主动
槽和每槽五个空辅助位在 HUD/暂停页可见且保存可靠。所有新增测试、完整相关
回归和 Release 构建通过；无生产路径使用测试注入或私有战斗快捷入口。
