# Stage 12 材质包资源

运行时材质包固定查找本目录下的三个内置图集：

- `environment.png`：1024 × 1024
- `actors.png`：2048 × 2048
- `effects_ui.png`：1024 × 1024

本 Task 2 尚未加入这些 PNG；它们将由 12-B、12-C、12-D 分别提供。因此当前构建发布时只会复制本说明文件，游戏启动会对每个缺失类别只警告一次，并安全保留现有程序绘制回退。图集到位后，发布后置步骤会将整个 `assets/stage12` 目录复制到可执行文件同级的 `bin/assets/stage12`，不需要运行时解析清单或在绘制热路径读取文件。
